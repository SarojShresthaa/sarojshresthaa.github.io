about

Umbraco & .NET developer in Kathmandu

I'm Saroj Shrestha. I build websites with Umbraco and .NET — mostly from Kathmandu, and since 2023 with ZAAKS!

I care about the backoffice feeling obvious for editors: clear document types, sensible Block Lists, and Razor that doesn't fight you every time content changes. When something repeats in the wild, I turn it into a package on GitHub — like Block Field Visibility for Block List fields.

Questions about Umbraco — greenfield, legacy, or "should we use this?" — are welcome. Use the contact page when you're ready; no pitch deck.
